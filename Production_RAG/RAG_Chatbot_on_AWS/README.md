# Build and Deploy RAG Chatbot on AWS

---
# Systems we will use
- S3 data/document storage
- OpenSearch Vector Database
- AWS knowledge base
- AWS Titan embeddings
- [LlamaIndex Agents](https://developers.llamaindex.ai/python/framework/understanding/agent/)
- LLM foundation model (e.g. OpenAI)
- Gradio (front-end instead of React.js)
- AWS ECR (container registry)
- AWS AppRunner (scale/deploy apps)
