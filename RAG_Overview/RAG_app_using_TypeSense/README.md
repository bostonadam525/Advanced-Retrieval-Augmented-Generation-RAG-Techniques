# RAG Application using TypeSense
- This is a RAG app created using Type Sense.


## What is Type Sense?
- In a nutshell, this is a blazing fast intuitive search engine, better than Elastic Search.
-  More about Type Sense here: https://typesense.org/


## Setup
- Make sure to add `typesense` to requirements.txt file. Also, make sure to run in git bash or command prompt: `uv add typesense`
- Create a free account.
- Launch free cluster (takes about 4-5 minutes).
- Next, need to create free API keys.
