# RAG Experiments - Basic to Advanced with LangChain

---
## Setup
- in the workspace folder fun: `uv init` (make sure uv is installed on your local machine first via the terminal for mac or windows)
- create venv: `uv venv`
- Activate with: `source .venv/Scripts/activate` (if on bash on windows)
- create file: `requirements.txt`
- install packages: `uv add -r requirements.txt`
- create folders for:
    - Data
    - Notebooks
- run: `uv add ipykernel`
- always maker sure to select the kernel when running jupyter notebooks.
